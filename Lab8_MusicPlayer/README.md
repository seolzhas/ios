# Lab 8 — Шәмші Қалдаяқов Music Player

UIKit + Main.storyboard + 3 UIStackViews + Auto Layout + AVAudioPlayer.

## Треки
1. **Арыс жағасында** — Diana Sharapova
2. **Қайықта** — Айгуль Гардисламова
3. **Әнім сен едің** — Айдос Жабағин
4. **Қайдасың** — Балуан Беркенов
5. **Бәрінен де сен сұлу** — Дархан Жолдыбаев
6. **Бақыт құшағында** — Расул Жармағамбетов
7. **Отан** — Тахауи Рахметов
8. **Қуаныш вальсі** — Төлеген Рахымбаев
9. **Шынарым** — Фархат Кубиев
10. **Ол жалғыз, біз екеуміз** — Бақтыгүл Бисембаева & Динара Надилбекова

Все 10 аудиозаписей предоставлены пользователем и перекодированы в AAC (.m4a) для проекта.
Имена исполнителей соответствуют именам предоставленных файлов. Обложки — тематические иллюстрации проекта.

## Возможности
Play/Pause, Next/Previous, циклическое переключение, автоматический переход к следующему треку.

## Запуск
Откройте `Lab8MusicPlayer.xcodeproj` в Xcode, выберите iPhone Simulator и нажмите Run.

## Для сдачи
Добавьте скриншоты с iPhone SE (3rd gen) и iPhone 16 Pro Max и запись экрана на 20–30 секунд.
Публикуйте аудиофайлы только при наличии прав на распространение.
